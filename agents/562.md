# Frequent and recent album lists

Subsonic `scrobble` increments play metadata on song annotations. The album list query incorrectly checked album annotations for `frequent` and `recent`, making those library-wide lists empty after normal playback. Aggregate `play_count` and latest `play_date` from every song annotation belonging to each album, and use the same rows to qualify albums. Preserve global ranking, filtering, pagination, response fields, and user-specific annotation mapping used by the endpoint.

The real SQLite regression test must exercise zero history, scrobbles, multiple users and songs per album, ordering, pagination, and folder filtering. Do not add schema changes or write production data.
