# 剩余同发行专辑显示归组

## 目标

把已确认同名且曲目对应的四组专辑纳入显示分组；保持所有专辑、曲目、实例、附件与 R2 对象不变。

## 步骤

1. 在 production D1 primary 上只读核对专辑身份、轨数、封面、分组占用与曲目关系。
2. 生成精确 ID 守卫 SQL，在隔离数据库验证成功与快照失效回滚。
3. 复核最新 primary 快照，执行一次分组写入，随后核对组、成员及音轨总量。
4. 在已登录的 EdgeSonic 页面确认一组只显示一张卡，仍可进入各版次。

## 范围

Lost In Tianyi、华哉有夏·贰、洛 LUO、无事发生。不同音频版本保留，精确 PCM 去重另行审核。
