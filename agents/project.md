# EdgeSonic Project Index

> Last updated: 2026-09-26

## Project goal

EdgeSonic manages a personal music library with Cloudflare Workers, D1, and R2.

## Technology

TypeScript Worker, Cloudflare D1/R2, Node.js tooling, and PowerShell test scripts.

## Modules

- `worker/`: Worker application and database schema.
- `tools/`: local audit utilities.
- `test/`: isolated test and rehearsal inputs.
- `agents/`: internal audit records.
