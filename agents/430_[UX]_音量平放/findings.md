# 调研记录

- [现象] `PlayerBar.vue` 的 `.pb-audio-settings` 当前使用列布局，导致音质控件位于音量控件下方。
  -> [结论] 仅调整播放器右侧布局为行布局即可保持现有组件职责。
- [现象] `PlayerVolumeControl.vue` 的百分比使用绝对定位在滑条内部右下角。
  -> [结论] 将百分比锚定到滑条右侧，避免覆盖滑条；现有 `adjusting` 状态已经覆盖聚焦和拖动。
- [范围] 不修改 `.pb-progress` 或主题进度条样式，也不改变静音、键盘、移动端弹窗逻辑。
- [核查] 百分比最长值为 `100%`，需要至少 4ch；桌面滑条容器固定预留 4.5ch，并将文字锚定在预留槽右侧，避免与音质按钮重叠或因 `v-if` 显示切换而跳动。
- [尺寸核查] 1440px 下滑条取 200px，音量图标/间隙/百分比槽约 271px；加音质选择、队列按钮和间隙后，右区 300px 不足，因此桌面 `.pb-right` 调整为 430px。移动端仍由媒体查询覆盖为自适应宽度。
- [弹窗核查] 移动端弹窗滑条同样固定预留 4.5ch，百分比不会盖住滑条且显示切换不改变弹窗布局。
