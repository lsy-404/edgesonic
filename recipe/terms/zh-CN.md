# 服务条款

## 一、服务说明

本页面提供的浏览器部署向导（以下称“安装器”）帮助你在你自己的 Cloudflare 账号下创建或恢复 EdgeSonic 实例。使用本安装器前，你需确认自己拥有并获得授权使用接下来填写的 Cloudflare 账号与 API Token；安装器创建或恢复的 Worker、D1 数据库、R2 存储桶均归属于你自己的 Cloudflare 账号，与本服务的运营者无关。

## 二、数据处理

- 浏览器无法直接调用 Cloudflare API（CORS 限制），因此安装器对 Cloudflare API 的请求会经由我们运营的一个无状态中转服务转发；该中转仅原样透传请求与响应，不记录日志、不持久化你的 API Token、R2 密钥或任何请求内容。
- 中转服务运行在 Cloudflare 平台上。作为基础设施提供方，Cloudflare 会对经过其网络的流量进行其平台级别的常规追踪与防滥用处理（例如 CF-Ray 请求标识、速率限制、Bot 检测、WAF 规则等）；这部分数据处理由 Cloudflare 依其自身条款和隐私政策独立执行，不受我们控制，我们也无法就此代表 Cloudflare 作出任何保证。
- 你填写的 Cloudflare 凭证仅保存在当前浏览器标签页的会话存储（sessionStorage）中；关闭标签页，或部署成功/失败后，凭证即被清除。我们不会以任何形式收集、转发给第三方或长期留存这些凭证。

## 三、资源与数据责任

- 安装器会创建或恢复后续页面指定名称的 Worker、D1 数据库和 R2 存储桶；检测到已有 Worker 时，安装器不会未经单独确认就覆盖它。
- 若你填写的 D1 数据库或 R2 存储桶名称已存在，安装器会直接复用而不是报错。你需自行确认这些名称在你的账号下确未被占用，避免安装器误接入无关的数据。
- 使用“恢复已有实例”时，安装器会尽力保留数据，但我们不对因误操作、并发部署、Cloudflare 侧故障或其他不可控因素造成的数据损坏承担完全恢复的责任，请自行为重要数据保留独立备份。

## 四、服务可用性

本安装器及其中转服务按“现状”提供，不附带任何可用性、正常运行时间或持续可用的保证。服务可能因维护、Cloudflare 侧变更、滥用防护措施触发或其他原因而暂时或永久不可用，恕不另行通知；请勿将其作为长期依赖的基础设施。

## 五、服务用途

本安装器及其中转服务完全免费，仅用于帮助你部署自己的 EdgeSonic 实例。我们从未、也不会以任何形式对此收费。如果你是向他人付费购买了所谓的“访问权限”或“部署服务”才看到这个页面，那是骗局——请向对方索要退款，并给予差评。
